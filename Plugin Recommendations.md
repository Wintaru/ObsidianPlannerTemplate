# Plugin Recommendations

## Currently Installed

| Plugin | Purpose |
|--------|---------|
| **Obsidian Tasks** | Task tracking with due dates, priorities, recurrence, queries |
| **Templater** | Advanced templates with variables, dates, scripting |
| **Mermaid Tools** | Diagram toolbar for Mermaid.js |
| **Insta TOC** | Auto table of contents |
| **Dataview** | Query engine for pulling structured data from notes |
| **Calendar** | Sidebar calendar widget for navigating daily notes |
| **QuickAdd** | Quick capture, templated note creation, macro chaining |
| **Periodic Notes** | Weekly, monthly, quarterly, yearly note templates |
| **Tag Wrangler** | Rename, merge, search tags via right-click |
| **Homepage** | Opens a specific note on startup |
| **Omnisearch** | Relevance-ranked fuzzy search across vault |

## Install Next (after core workflow is stable)

| Plugin | What it does | Why |
|--------|-------------|-----|
| **Excalidraw** | Freeform whiteboard/sketching inside Obsidian | Architecture whiteboarding, brainstorming, visual project maps. Drawings can contain wikilinks. Most downloaded Obsidian plugin (~2.5M). |
| **Strange New Worlds** | Inline link/reference counts next to wikilinks | See at a glance how connected each note is. Surfaces orphaned vs. well-linked notes. |
| **Kanban Plus** | Markdown-backed Kanban boards | Visual project boards (Backlog / In Progress / Done). Queryable by Dataview since it's just markdown. |
| **TimeStamper** | Insert timestamps with a hotkey | Log project switches, meeting start/end times. Understand where your time goes. |

## Install As Needed

| Plugin | What it does | Why |
|--------|-------------|-----|
| **Notebook Navigator** | Two-pane file explorer with tag browsing | Browse by folder OR by tag in the sidebar. Useful as vault grows. |
| **Journal Review** | "On this day" past entries | Surfaces journal entries from the same date in previous years. Valuable after ~6 months. |
| **Automatic Linker** | Auto-converts plain text to wikilinks on save | Type names and projects without brackets -- auto-linked if a note exists. Needs careful config. |
| **Obsidian Git** | Git-based backup and version control | Automatic commits on a schedule, diff viewer, push/pull from remote. Great for backup. |

## Skipped (and why)

| Plugin | Why not |
|--------|---------|
| **Datacore** | Faster Dataview successor, but still early/unstable -- revisit later |
| **Obsidian Projects** | Discontinued May 2025 |
| **Jira/GitHub integrations** | Adds complexity; only worth it if you need live sync |
| **PARA Workflower** | Only if you follow the PARA method specifically |
